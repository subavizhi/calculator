# Python Calculator

This project is an **Advanced Python Calculator** built using Python.
It supports basic arithmetic operations along with advanced features like power, square, square root, and percentage.

## 🚀 Features
- Basic operations (Add, Subtract, Multiply, Divide)
- Power, Square, Square Root
- Percentage calculation
- Error handling
- User-friendly interaction

## ▶️ How to Run
```bash
python calculator.py
